# MisProyectosJava

Colección de programas en Java desarrollados durante mi proceso de aprendizaje.  
Incluye ejercicios, prácticas y proyectos desarrollados en clase como parte de mi formación en desarrollo de aplicaciones multiplataforma.

## 📚 Descripción general

Cada archivo `JavaApplication###.java` corresponde a un ejercicio o mini proyecto independiente, desarrollado para practicar distintos conceptos de programación en Java.  
Estos códigos reflejan mi progreso en el aprendizaje de estructuras básicas, programación orientada a objetos y resolución de problemas con código.

## 🧠 Temas trabajados

- Estructuras de control (`if`, `else`, `switch`, `for`, `while`)
- Arreglos y colecciones
- Métodos y funciones
- Clases, objetos y encapsulamiento (POO)
- Entrada y salida de datos
- Manejo de excepciones
- Uso de operadores y estructuras lógicas

## 🗂️ Organización

Los nombres de archivo (`JavaApplication111.java`, `JavaApplication112.java`, etc.) siguen la numeración original usada en clase.  
Más adelante, planeo reorganizarlos por temas para facilitar la lectura y el acceso.
